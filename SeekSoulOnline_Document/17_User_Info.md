# 个人信息

## 查看个人信息

点击右侧【头像】，选择【个人信息】弹出个人信息窗口，可查看相关信息。点击【取消】或【 x 】即可退出。

## 编辑个人信息

在个人信息窗口页面，可修改密码、姓名、单位、邮箱和电话信息，点击【保存】即可更新。

> [!NOTE]
> 每次修改时均需输入密码，密码输入框可设置显示/隐藏密码，带 * 为必填项。
