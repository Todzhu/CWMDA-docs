# 开始分析

## 资源总览

登录云平台后会进入“资源总览”，该界面主要包含四部分内容：

1. 《[**我的项目**](#我的项目)》：用于创建项目及单细胞分析流程，可进行“[**细胞注释**](./cell-annotation)”及单细胞相关图片绘制。
2. 《[**我的数据**](./datas)》：展示样本信息，包括标准分析及用户上传的样本信息。
3. 《[**我的数据库**](./my-database)》：查看已收集的公共数据库，用户也可以自定义数据库用于后续“[**差异富集**](./differential-enrichment)”分析。
4. 《[**我的基因集**](./my-genesets)》：查看已收集的注释细胞类型及其 marker，用户也可以自定义 marker 基因集用于注释及画图。

## 我的项目

“我的项目”主要用于管理分析流程。同一个项目下可进行大群及亚群的分析，如需新增或删减样本重新分析，建议用户创建新的项目。项目创建流程如下：

1. 点击【新建项目】。

<div align="center">
<img src="/processed-assets/39c50b3120-screenshot_2025-07-21_17-13-20.DTBzlcg4.png" width="40%" />
</div>

2. 填写“分析项目名”及“描述”，点击【提交】保存项目，在弹出的提示信息中点击【确定】完成项目信息保存。
