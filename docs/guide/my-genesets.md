# 我的基因集

“我的基因集”是已收集的用于注释和画图的基因集，目前主要收集小鼠和人一些细胞类型及其经典 marker 基因。用户可通过【新建基因集】自行收集和存储 marker 基因，用于注释及画图。

> [!NOTE]
> 建议优先整理常用细胞类型及 marker 基因，便于后续注释和可视化分析。

1. 【查看】基因集：每个基因集主要包括基因集名称、物种及基因预览，基因预览中基因以逗号分割。
