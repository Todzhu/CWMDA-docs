# 亚群选择

在“亚群选择”模块允许用户根据感兴趣的 Cluster 或 Cell Type 创建新的数据集（子集），以便进行更深入的分析。您可以按照自定义规则（与“[**画图工具**](./visualisation)”中【添加标签】规则一致），将感兴趣的细胞类群进行提取和存储。主界面分为两部分内容：“亚群选择”和“历史记录”。

> 亚群选择功能可帮助用户灵活筛选目标细胞群体，便于后续深入分析。

## 亚群选择

包括五列内容：“参数”、“运算符”、“值”、“条件”和“子集名称”。

1. “参数”用于对细胞进行分组的各种标签，“运算符”包括等于 “==” 和不等于 “≠”，“值”为所选参数中的各种细胞组名，“条件”包括交集 “and” 和并集 “or”；“子集名称”为所选感兴趣细胞类群的命名，需以英文字母开头，可包含英文字母、数字和下划线。
2. 在条件后有【+】按钮，可用多个条件筛选子集，也可用【-】按钮删除某个条件。填写完毕后点击右上方【提交】按钮，即可按定义规则筛选亚群并记录在历史记录中。

## 历史记录

历史记录为所有筛选亚群的表格。

1. 与云平台所有表格一致，可通过搜索框进行模糊搜索，也可在表头进行排序和筛选操作。最重要的是操作列，可查看对应亚群的筛选条件，也可对筛选的亚群进行删除。
2. 状态显示“已完成”的亚群数据可在“[**资源总览**](./getting-started)”下的“[**我的数据**](./datas)”中找到。
3. 点击某子集后的加号按钮，新建亚群流程时数据会自动选中该子集。
